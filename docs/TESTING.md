# 验证范围

## 自动检查

运行 `python3 scripts/check.py`，使用隔离目录测试安装、卸载和 shell 集成，使用模拟 Hammerspoon API 测试状态逻辑。依赖测试使用替身命令，不会在开发机器上安装或重装 Hammerspoon。

覆盖包括：重复安装、保留配置、备份回滚、旧代码与损坏标记检测、输入法选择与取消、显式输入源校验、参数与退出码保留、通知失败不中断 Agent、Homebrew/GitHub 选择、下载校验、终端状态隔离、超时恢复和旧查询结果丢弃。

打包检查验证：与目录名无关的文件命名、版本一致性、必要文件、执行权限、文档链接、校验和，以及不包含 Git 元数据或临时文件。

## 人工验收

自动测试不等于真实输入法体验验证。发布或调整运行逻辑后，在实际 Mac 上检查：

1. 普通 Ghostty shell 为英文，运行 Agent 后为所选中文输入法，退出后恢复英文。
2. 两个标签和同一标签的两个分屏来回切换时，各自遵循自己的状态。
3. 后台 Agent 退出，不错误切换当前终端。
4. 离开 Ghostty 后，其他应用的输入法规则正常。
5. 同一终端内手动切换输入源，确认后不会被连续覆盖。
6. Hammerspoon 重载后恢复已上报的状态，关闭终端后清理历史记录。
7. 输入法不可用、权限被拒绝或 Hammerspoon 未运行时，Agent 本身仍能执行。
8. 安装、更新、卸载和重新打开终端后，相关行为与文档一致。

测试下载依赖时区分：是否实际访问网络、是否校验真实发行包、是否实际写入 Applications。不要将模拟安装报告为真实安装通过。

## 支持边界

当前不承诺 tmux、SSH、后台 Agent、挂起/恢复、复杂嵌套 shell 或同一终端并行 Agent 的完整行为。系统输入源 ID 正确也不意味着输入法内部中英文模式、候选框和首字符已就绪。
